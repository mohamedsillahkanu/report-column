Process

  1. Upload: CSV or Excel file
  2. Select: Indicator columns
  3. Choose: Condition to apply
  4. Generate: Report column (1/0)
  5. Download: Updated file

Available Conditions

  • Any Value > 0: Report if any indicator reported
  • Sum > Threshold: Report if sum exceeds value
  • All Values > 0: Report only if all indicators reported
  • Count >= N: Report if N or more indicators have values

Output

  • New "report" column added
  • 1 = Condition met (reported)
  • 0 = Condition not met
  • Download as Excel or CSV
  • Ready for heatmap analysis
